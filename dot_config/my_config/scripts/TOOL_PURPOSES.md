## Version Management & Build Tools

### mise ✅ PRIMARY
- **Purpose**: Universal version manager (asdf clone in Rust)
- **Manages**: Python, Node, Go, Deno, Bun, language tools, pipx packages, npm packages
- **Why chosen**: Faster than asdf, single tool for all languages, integrated with mise tasks
- **Config**: `~/.config/mise/config.toml` (50+ tools)

### uv ✅ KEEP
- **Purpose**: Fast Python package installer and environment manager
- **Usage**: Primary Python package manager, replaces pip for speed
- **Integration**: Works with mise for Python version management
- **Config**: `UV_PYTHON_DOWNLOADS=never`, `UV_PYTHON_PREFERENCE=only-system`

### pipenv
- **Purpose**: Python virtual environment manager
- **Status**: ⚠️ REVIEW - Overlaps with uv and mise
- **Decision needed**: Determine if still needed with uv + mise workflow

## Shell & Terminal

### zsh + oh-my-zsh ✅ KEEP
- **Purpose**: Primary shell with plugin system
- **Plugins**: 10 active (git, jj, python, timer, tmux, auto-notify, you-should-use, zsh-completions, zsh-autosuggestions, zsh-syntax-highlighting)
- **Config**: `~/.config/my_config/private__omz.sh`

### atuin ✅ KEEP
- **Purpose**: SQLite-backed shell history with search
- **Why**: Better than default history search, syncs across machines
- **Usage**: Ctrl+R for search, disabled up-arrow to use zsh history navigation

### tmux ✅ KEEP
- **Purpose**: Terminal multiplexer
- **Usage**: Session management, persistent terminals
- **Config**: `~/.tmux.conf`
- **Integration**: OMZ plugin for shortcuts (tsh function)

### wezterm ✅ KEEP
- **Purpose**: Terminal emulator with custom tab colors/titles
- **Config**: `~/.wezterm.lua` (265 lines)
- **Why**: Better customization than alternatives

### GitHub Configuration Management Tools ⭐ NEW
- **Purpose**: Automate and audit GitHub repository settings across all repos
- **Scripts**:
  - `github_config_repo.sh` - Apply standard config to a repo
  - `github_audit_repos.sh` - Audit repo configurations
  - `github_bulk_config.sh` - Bulk operations across repos
- **Aliases**:
  - `gh-config-here` - Configure current repository
  - `gh-audit-here` - Audit current repository
  - `gh-audit` - Audit specified repo or all repos
  - `gh-bulk` - Bulk operations with options
- **Features**:
  - ✅ Auto-delete branches after merge
  - ✅ Consistent merge strategy settings
  - ✅ Branch protection rules
  - ✅ Bulk configuration updates
  - ✅ Repository auditing and compliance
- **Documentation**:
  - Full guide: `~/.config/my_config/scripts/GITHUB_CONFIG_MANAGEMENT.md`
  - Quick start: `~/.config/my_config/scripts/GITHUB_CONFIG_QUICKSTART.md`
- **Usage Examples**:
  ```bash
  gh-config-here              # Apply standard config to current repo
  gh-audit --all              # Audit all repositories
  gh-bulk --auto-delete       # Enable auto-delete on all repos
  gh-bulk --summary           # Show configuration summary
  ```
- **Why needed**: Personal GitHub accounts don't have organization-level settings, so consistent configuration across repos requires automation

### difftastic ✅ KEEP
- **Purpose**: Structural diff tool
- **Usage**: Git external diff tool
- **Why over git-delta**: Better for code structure changes

### git-delta ✅ KEEP
- **Purpose**: Syntax-highlighting diff pager
- **Usage**: Git log pager (different use case than difftastic)
- **Why keep both**: difftastic for diffs, delta for logs

### mergiraf ✅ KEEP
- **Purpose**: Intelligent merge driver
- **Usage**: Automatic conflict resolution for git merges

## Notes

**Package Manager Philosophy:**
- **brew**: System tools, GUI apps, tools not available in mise
- **mise**: All language-specific development tools (Python, Node, Go, etc.)
- **uv**: Fast Python package installation
- **npm/pipx**: Managed through mise, not directly

**When Adding New Tools:**
1. Check if already installed under different name
2. Document purpose in this file
3. Choose appropriate package manager (prefer mise for dev tools)
4. Update machine snapshot after installing

**When Removing Tools:**
1. Document removal reason in SIMPLIFICATION_CHANGES.md
2. Remove from all package managers
3. Update this file with ❌ and reason
4. Regenerate machine snapshot
